# 云端验收步骤

状态：2026-10-29，当前只有一个真实微信账号。自动测试使用隔离的内存身份；下面涉及 A、B 两个微信身份的项目尚未完成真人验收。

## 准备

- A、B 都有本小程序的预览或体验权限，打开同一版本，页面显示已连接云端。现有云环境为 `cloud1-d4g7jugs8b44f8072`。
- 使用明确标注“验收”的目标与小队。已存在个人目标或小队时先保留，避免为了测试覆盖记录。
- 图片使用无个人信息的示例图；选中后先核对文件名和缩略图。不要选择后台截图、聊天记录或证件。
- 预览码过期时，在开发者工具重新生成。邀请卡有效期为 7 天，与预览码有效期不同。

## 单账号手机检查

| 操作 | 应看到的结果 |
| --- | --- |
| 创建一个目标 | 只能选早睡、多喝水、锻炼，允许填写具体内容；已有目标时不能再创建第二个进行中目标 |
| 打卡，填写感想并选择示例图片 | 保存成功后首页、战绩均增加一天；图片可打开 |
| 当天再次修改感想 | 仍只有当天一条记录，完成天数不再增加 |
| 退出小程序后重新打开 | 云端目标、感想、照片及统计仍在；网络错误应显示失败和重试入口 |
| 拒绝相册或取消选图 | 不应显示上传成功，无图片也可以打卡 |
| 结束一个测试目标，再看战绩 | 历史记录保留，可选择旧目标查看 |

日期以北京时间为准。跨日自动测试已覆盖，手机跨日检查仍应在实际次日完成，不通过修改身份或日期制造真机验收结果。

## 两个微信身份检查

以下涉及发送邀请的步骤由测试者在微信中操作。

| 步骤 | 操作 | 验收结果 |
| --- | --- | --- |
| 1 | A 创建验收小队，B 用邀请码或邀请卡加入 | 双方看到 2 名成员；重复加入不会增加人数 |
| 2 | A 保存一条含测试感想和示例图片的记录，B 查看小队 | B 看到目标及统计，看不到感想和照片 |
| 3 | A 生成默认进度卡并发给 B | B 能读取实时进度，不能修改 A 的目标；无感想、无照片 |
| 4 | A 撤销该卡，B 重新打开 | 显示分享失效 |
| 5 | A 明确打开“附上图片”生成新卡给 B | B 能查看示例图片，仍看不到感想；测试后 A 可撤销此卡 |
| 6 | A 生成督促邀请，B 打开但不接受 | 尚未建立监督关系；“我的”不出现该关系 |
| 7 | B 主动接受督促邀请 | 双方“我的”出现对应关系；B 可查看 A 的进度 |
| 8 | 在 A 当天尚未完成且目标未结束时，B 点击提醒 | A 打开小程序后看到站内提醒；B 同一路径当天不能重复提醒 |
| 9 | A 将提醒标为已读后重新进入 | 已读状态保留 |
| 10 | A 或 B 解除监督关系，双方刷新 | 关系消失；旧页面的提醒请求被拒绝 |
| 11 | B 退出小队后刷新 | 小队中不再显示 B；B 不能继续通过旧页面发送小队提醒 |
| 12 | A 从分享页面分享到好友与朋友圈，B 打开 | 打开对应目标或小队邀请；需在真实微信客户端分别检查 |

监督关系与分享链接分别撤销。解除监督后，尚未撤销且仍有效的分享链接仍可提供它原本授权的只读访问；已下载的图片与截图也不会被撤回。服务端签发的图片临时 URL 有效期为 10 分钟。
